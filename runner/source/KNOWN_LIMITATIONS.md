# Known limitations and acceptance scope

- Host reasoning supplies semantic work and real tool observations. Python
  verifies binding and structure, not source truth or honest reading. Challenger
  shares the host context and is not isolated independent verification.
- Human-message origin is authenticated by the trusted host, not by a signature.
  Executor JSON cannot create user events. Replay preserves the chain but cannot
  establish human authenticity from self-hashes. Retain external package hashes.
- Seven actual XMLs pass interface checks. Offline host doubles exercise controls,
  while separate recorded host runs demonstrate source-grounded podcast/article
  creation, qualified payroll/property analysis, membership strategy and labeled
  workweek scenarios. All referenced source files were found. The two-book case
  now completes all nine tasks with DETERMINED after full unabridged text reading
  and source-specific review. Clean acceptance executes fresh sessions using
  these recorded observations and reviewed work; it does not call a new model.
- BOUNDED_COUNT and UNTIL_CONDITION have no task-body binding in Compiler 1.0;
  Runner requires an explicit host execution plan and Challenger PASS before
  work. It never infers body bindings from order, numbering or prose similarity.
  Ambiguous plans remain held/rejected. Zero counts, overlapping/nested bodies,
  non-convex dependency bodies and branch-local bodies are unsupported. Positive
  bounded counts and until loops have a 100-round cap; exhaustion cannot release
  as successful termination. OVER_COLLECTION retains existing member checks.
- Reference renditions are immutable trusted-host tool assertions, capped at
  8 MB canonical text total. Hash binding does not prove faithful extraction or
  reading. Source-local lexical retrieval is deterministic, not semantic search.
  Executor-derived premise graphs preserve identities but semantic support and
  sufficiency still require actual host review against the source passages.
- Artifacts support UTF-8 text or explicit BASE64-encoded binary bytes. Format
  fidelity still requires host rendering/inspection before Challenger approval.
- Selection metadata is conservative: unresolved USER_ONLY withholds
  selected_subject_ref. Ranked recommendations may still be expressed as such.
- SYSTEM caps: 1,000 observed sources, approximately 33 MB raw observed bytes,
  5,000 evidence records, 1,000 committed task executions, two repair passes;
  intake 5,000 members, 64 MB/file, 128 MB total; XML 16 MB.
- Offline wheels cover Linux CPython 3.11–3.14 and Windows CPython 3.14 x64.
  Other platforms need compatible pinned dependencies installed separately.

Semantic completion acceptance and package verification are reported separately
from deterministic test success. No independent certification occurred. Earlier
qualified payroll/property/workweek outcomes remain legitimate no-result outcomes;
the Mace scan's missing printed-page ranges remain disclosed in its product.
