# Deployment prerequisite: original ChatGPT Project Instructions

The owner describes a two-command user workflow (`COMPILE` and `RUN`) in currently configured Projects. This package documents that workflow but does not independently verify how those two chat commands are configured in a new account. Both supplied `01_START_HERE` files point to project instruction files that were **not among the six supplied attachments and were not found inside either runtime ZIP**:

- `00_PROJECT_INSTRUCTIONS_COMPILER.txt`
- `00_PROJECT_INSTRUCTIONS_RUNNER.txt`

This GitHub package is a complete public-facing source and runtime archive *for the supplied files*; it is **not** a claim that the missing Project settings were reconstructed. A new ChatGPT Project requires its correct original instructions to reproduce the current daily workflow. Obtain the configured settings text from the user's current Compiler and Runner Projects, review it for secrets and internal URLs, then decide whether to publish a redacted version. Do not confuse historical Prompt Forge Project Instructions for a different release with these exact 1.0.0 files.

A hosted model's real Python/file/web-tool availability must also be validated in the target account; local self-checks alone cannot establish the UI deployment behavior.
